# Vista previa — cristinamagrina.ca

Copia temporal y **pública** de la web nueva de Cristina Magriñá Psychology, para poder
revisarla desde cualquier dispositivo antes de publicarla en el dominio.

- **No es la web en producción.** La web actual sigue siendo <https://www.cristinamagrina.ca>.
- Lleva `noindex, nofollow` en todas las páginas y `robots.txt` bloqueando el rastreo, para
  que no compita en Google con el sitio real cuando se publique.
- El código fuente está en un repositorio privado. Este repo solo contiene la copia
  compilada de la vista previa y se borrará cuando la web esté publicada.

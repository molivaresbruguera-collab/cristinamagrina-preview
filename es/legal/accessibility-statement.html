Declaración de accesibilidad

Última actualización: agosto de 2026

Traducción de cortesía. Esta página es una traducción del texto original en inglés, que es el que prevalece a efectos legales. Puedes consultarlo en la versión en inglés.

Cristina Magriñá Psychology se compromete a hacer que esta página web sea accesible y fácil de utilizar para el mayor número de personas posible, incluidas aquellas que utilizan tecnologías de asistencia como lectores de pantalla, magnificadores de pantalla, programas de reconocimiento de voz o navegación exclusivamente mediante teclado.

Qué significa la accesibilidad web

Una página web accesible permite que las personas con discapacidad puedan acceder a la información y navegar por el sitio con un nivel de facilidad e independencia similar al del resto de visitantes. La accesibilidad puede favorecerse tanto mediante el diseño y la funcionalidad de la página web como mediante el uso de tecnologías de asistencia.

Estado de conformidad

Esta página web se ha desarrollado con el objetivo de cumplir las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1, nivel AA. Este es un objetivo de accesibilidad y no el resultado de una auditoría certificada. La página ha sido desarrollada y revisada manualmente teniendo en cuenta estas pautas, pero no ha sido auditada ni certificada de forma independiente.

La accesibilidad es un proceso continuo, y seguiré revisando y mejorando la página web siempre que sea posible.

Medidas de accesibilidad implementadas

  • El idioma de la página web y de cada una de sus páginas está indicado en el código.
  • Las páginas utilizan una estructura de encabezados clara y lógica, con un orden de lectura que sigue el orden visual previsto.
  • Las diferentes áreas de la página, como la cabecera, la navegación, el contenido principal y el pie de página, están identificadas para facilitar la navegación mediante tecnologías de asistencia.
  • Un enlace de “Saltar al contenido” es el primer elemento al que se puede acceder mediante el teclado en todas las páginas.
  • Todas las funcionalidades de la página web, incluido el menú de navegación y los paneles desplegables de preguntas, pueden utilizarse únicamente mediante el teclado.
  • Los elementos interactivos cuentan con indicadores visibles de enfoque.
  • Las combinaciones de colores entre texto y fondo se han seleccionado para cumplir los requisitos aplicables de contraste.
  • Las imágenes que transmiten información incluyen texto alternativo, mientras que las imágenes decorativas están ocultas para las tecnologías de asistencia.
  • El movimiento y las animaciones se reducen automáticamente para las personas cuyo sistema tenga activada la opción de reducir el movimiento.
  • El texto puede ampliarse y el diseño se adapta sin pérdida de contenido ni funcionalidad.

Limitaciones conocidas

Aunque he tomado medidas para hacer que esta página web sea accesible, es posible que algunos contenidos o funcionalidades no sean plenamente accesibles para todas las personas. Si encuentras alguna barrera de accesibilidad, te invito a ponerte en contacto conmigo para que pueda conocer el problema y, cuando sea posible, encontrar una alternativa que te permita acceder a la información o recibir la ayuda que necesitas.

Consultas, incidencias y sugerencias

Si encuentras algún problema de accesibilidad en esta página web, necesitas información en un formato alternativo o necesitas ayuda para ponerte en contacto conmigo y solicitar una cita, puedes escribirme:

  • Contacto para cuestiones de accesibilidad: Cristina Magriñá
  • Email: info@cristinamagrina.ca

Mi objetivo es responder a las consultas relacionadas con la accesibilidad en un plazo de 5 días laborables.

Agradezco cualquier comentario sobre la accesibilidad de esta página web y tendré en cuenta las solicitudes razonables de formatos alternativos o de otras formas de acceder a la información.
